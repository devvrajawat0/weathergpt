🛡️ Feasibility, Technical Risks & Mitigation

Risk assessment and production resilience strategy

Risk 1: Third-Party API Downtime or Rate Limiting

Satellite data API failures could disrupt live weather card updates.

Mitigation Strategy: Keyless Open-Meteo 10k daily call limit + failover fallback models & client Service Worker (`sw.js`) caching.
Risk 2: AI Weather Number Hallucination

LLM generating false rain or temperature values in natural language chat.

Mitigation Strategy: System prompt context injection forcing strict JSON telemetry binding. LLM is restricted to formatting.
Risk 3: API Key Exposure in Open Repositories

Client-side browser bundles leaking private API keys.

Mitigation Strategy: Keys stored strictly server-side in `.env.local` inside Next.js server API routes (`/api/chat`, `/api/tts`).
